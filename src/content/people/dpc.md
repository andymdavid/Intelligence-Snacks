dpc is a software engineer and long-time open-source user and contributor. His [technical writing](https://dpc.pw/) covers Rust, developer tools, software architecture and security, including work on cargo-crev and the Fedimint ecosystem.

His public project list includes Fedimint, the federated e-cash system; Tau, a command-line coding agent; and Rostra, a peer-to-peer social network. He also develops tools around code review and local development workflows. These projects give his writing a practical foundation: the questions are how to build and maintain software people can run, how to assess dependencies, and how to use new coding tools without giving up control of the development environment.

He writes about building Tau, using AI coding agents and protecting development environments. His approach treats agents as capable tools that still need clear architecture, isolation and human review. On Intelligence Snacks, he discusses how AI changes software craft and the way developers organise their work.
