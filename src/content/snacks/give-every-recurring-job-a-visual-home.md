A universal chat can ask an agent to do almost anything, but it also makes every activity look the same. That becomes difficult when someone is managing many kinds of work at once. A dedicated app gives one job a recognisable piece of visual space, helping the user understand where they are, what matters there and what kind of attention the work needs.

The useful interface changes with the distance from the task. Pete described a 30,000-foot chat for broad oversight, a two-foot chat for close supervision and separate apps that visualise particular domains. In Flight Deck, he also creates channels for distinct working modes, from quick dialogue to longer feature work. Each surface frames the agent differently instead of forcing every interaction into one undifferentiated stream.

Cheap software does not mean an interface should be regenerated on every visit. For recurring work, the better pattern is to build a personal visual shape once, keep it familiar and revise it when the job changes. Snack Studio followed that path. Its original screens exposed each pipeline so Andy could test failures and build trust, then the interface could collapse into a simpler view once the process was reliable.
