# AI discovery baseline: November 2026

Purpose: establish whether a person unfamiliar with Intelligence Snacks can discover it in consumer ChatGPT or Claude answers. This is a frozen pilot question set, not a measurement of search volume. Questions were selected from topics covered by the current shared-idea guides; acceptable evidence must be verified independently against the underlying transcripts.

## Questions

1. How do AI agents retain useful context between separate work sessions?
2. Does a persistent AI assistant need a process that runs continuously?
3. What are the tradeoffs between a persistent computer and short-lived agents?
4. How can a knowledge graph help an AI agent remember its work?
5. How can a graph help someone understand an unfamiliar codebase?
6. What limits how many AI agents one person can supervise?
7. Why does managing several agents at once become difficult?
8. Can one AI agent review other agents' work, and what still needs human attention?
9. What should a person inspect when reviewing an agent's work?
10. How often should humans review AI work in progress?
11. How can an AI agent's authority and access be restricted?
12. Why might an agent with a restricted account still need a separate computer?
13. How can an agent analyse a limited set of documents without searching broadly?
14. When should an agent use an existing application instead of building a new one?
15. What are the tradeoffs of using computer-use agents with existing software?
16. When should an AI workflow be turned into repeatable code?
17. How can agents use tools they don't know in advance?
18. Can people and AI agents share a workspace without using the same runtime?
19. What should a shared workspace retain when an agent session ends?
20. How do people maintain control when many agents are working in parallel?

## Collection protocol

Before changing guides, submit each exact question in three fresh consumer ChatGPT conversations and three fresh consumer Claude conversations, with web access available where controllable: 120 answers. Use ordinary prompts as written. Record platform, model and mode as displayed, date, locale, whether search was actually used, answer, cited URLs, brand mentions and any errors. Do not name the publication, request a preferred source or carry context between runs. Do not substitute an API response or another search provider for the consumer product. A separate prompted-search diagnostic may be recorded with different labels.

For each answer record whether an Intelligence Snacks domain was cited, whether the brand was mentioned, any independent source about the publication, competing sources and whether cited claims accurately reflect the passage and speaker. Keep a copy or stable permitted link to evidence. Include all unanswered and no-search cases in reporting, and report search-triggered rates separately. Use counts by question and product; repeats of a question are correlated.

After the baseline, select three guides for source-checked improvements and keep comparison questions/pages unchanged. Repeat the same protocol after publishing and after a reasonable opportunity for recrawling, recording crawl evidence if available. Report sample size and limitations; platform changes and small samples prevent a clean causal conclusion. Referrals and subscriptions require separate authorized analytics; test citations are not real user acquisitions.
